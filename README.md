# 📊 Projeto 03 — Análise de Viés Estatístico

## 🎯 Objetivo

Este projeto tem como objetivo identificar vieses em perguntas de pesquisas estatísticas e aplicar correções metodológicas para produzir dados mais confiáveis e neutros.

## 🧠 Conceitos Estatísticos Trabalhados

- Viés estatístico
- Neutralidade metodológica
- Qualidade dos dados
- Interpretação estatística
- Estruturação tabular
- Exportação de dados CSV

## 💻 Tecnologias Utilizadas

- Python
- Pandas
- Git
- GitHub
- VS Code


## 📂 Estrutura do Projeto

estatistica-projeto-03-analise-vies/
│
├── data/

│
├── src/
│   ├── planejamento_vies.py
│   └── correcao_vies.py
│
├── README.md
└── requirements.txt



## 🚀 Funcionalidades

- Identificação de perguntas enviesadas
- Análise de problemas metodológicos
- Correção de viés em pesquisas
- Criação de DataFrames estatísticos
- Exportação de análises em CSV

## ▶️ Como Executar

Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
Acesse a pasta:
    cd estatistica-projeto-03-analise-vies
Crie o ambiente virtual:
